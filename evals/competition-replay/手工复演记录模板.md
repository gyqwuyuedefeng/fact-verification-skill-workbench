## 三、完整比赛演示

| 序号 | 操作 | 必填记录 | 关键预期 | 实际结果 | 截图/备注 |
|---|---|---|---|---|---|
| F1 | 创建并冻结首个 Candidate | Candidate ID、版本号、content hash | 冻结内容不可变，生成版本卡 |  |  |
| F2 | 首轮 `BASELINE + Candidate` 评测 | Evaluation ID、dataset hash、GATE | 30 条、固定参数、状态 `COMPLETED`、门禁结果可下钻 |  |  |
| F3 | 建立首个 Stable | Stable ID、INITIALIZE revision | 只能使用门禁通过的首个 Candidate |  |  |
| F4 | 从 Stable 创建优化 Candidate | 新 Candidate ID、规则差异 | 原 Stable 不变；确定性 diff 与模型升级说明都可查看 |  |  |
| F5 | 三版本同条件评测 | Evaluation ID、四指标、GATE | `BASELINE + Stable + Candidate` 共享模型、输入、工具、证据快照和参数 |  |  |
| F6 | 历史/汇总/版本比较 | 历史批次数、版本评测次数 | 可切换历史；可看单版本多次汇总；可直接比较 Candidate 与 Stable |  |  |
| F7 | 注册并开启影子 | REGISTER/SHADOW_START revision | 无影子 PASS 时晋升应返回 409；普通用户只收到 Stable |  |  |
| F8 | 影子人工复核 | 上传 `04` 标记 PASS，上传 `05` 标记 FAIL | 管理页能按文件、复核状态和版本筛选；不把影子当金标准确率 |  |  |
| F9 | 晋升 | PROMOTE revision、新 Stable ID | 有 PASS 后允许晋升；后续新任务使用新 Stable |  |  |
| F10 | 回滚 | ROLLBACK revision、恢复 Stable ID | 后续新任务恢复上一版；历史记录追加保留 |  |  |
