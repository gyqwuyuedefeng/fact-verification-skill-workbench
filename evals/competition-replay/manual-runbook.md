# 手工复演清单

## A. 对话核验页

- [ ] BASELINE 文本任务能够发送。
- [ ] 01 材料解析实时显示文件名、格式或文本快照状态。
- [ ] 02 执行轨迹实时显示模型思考阶段、工具调用和完成/失败状态。
- [ ] 03 核验主张逐条显示原文定位、`VERIFIED`/`CONFLICT`/`INSUFFICIENT`、证据来源和人工介入提示。
- [ ] Markdown、TXT、CSV、Word、PDF、PPT、Excel 均可上传并解析，locator 与各格式结构一致。
- [ ] 有 Stable 时，同一输入可选择 Stable 重跑；页面不向普通用户暴露 Candidate/影子结果。

## B. Skill 实验室

- [ ] 能从初始 Skill 或当前 Stable 创建 DRAFT。
- [ ] DRAFT 可保存规则内容。
- [ ] 冻结后生成不可变 Candidate、版本号和 content hash。
- [ ] 可查看版本卡。
- [ ] 可生成相对上一版或当前 Stable 的确定性差异与 LLM 升级描述。

## C. 管理评测页

- [ ] 选择固定数据集 `public-tech-2024-v3`。
- [ ] 首次建立 Stable 时运行 BASELINE + Candidate。
- [ ] 后续运行 BASELINE + Stable + Candidate。
- [ ] 页面明确显示所有变体共享的数据集 hash、输入、模型、工具、证据快照和参数。
- [ ] 显示准确率、任务完成率、稳定性、人工介入率。
- [ ] 可切换历史评测运行。
- [ ] 可查看一个 Skill 版本的多次评测汇总。
- [ ] 可比较当前版本与上一版/正式版，并下钻具体失败样本。
- [ ] 可导出 Markdown/JSON 评测报告。

## D. 发布管理页

- [ ] 只有门禁通过的 Candidate 能注册。
- [ ] 开启影子后，普通用户仍只收到 Stable 正式结果。
- [ ] 管理员能查看同一输入的 PRIMARY/SHADOW 对照。
- [ ] 至少一条影子结果可人工标记 PASS/FAIL。
- [ ] 无 PASS 时禁止晋升；有 PASS 后允许晋升。
- [ ] 晋升只影响后续新任务，历史任务仍保留原版本。
- [ ] 回滚后续任务恢复到旧 Stable，并保留追加式发布历史。

## E. 现场讲解口径

- [ ] 先展示真实任务价值：材料事实核验与可追溯证据。
- [ ] 再展示赛题核心：同模型基线与 Skill 多版本的可复现对照。
- [ ] 最后展示版本资产：冻结、注册、影子、人工 PASS、晋升和回滚。
- [ ] 明确影子不是把 Candidate 结果偷偷给用户，而是复制同一输入在后台比较；用户正式答案始终来自 Stable。
