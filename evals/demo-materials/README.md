# 演示材料

这里集中保存现场输入材料；`01`—`03`、`06`—`08` 是纯模拟数据，`04`—`05` 是公司内部授权的真实主体测试材料：

- `01`：Markdown 多主张材料，覆盖主体、财务、知识产权、风险与关系。
- `02`：TXT 同名主体材料，展示主体不能唯一定位时必须停止错误拼接。
- `03`：CSV 表格材料，展示经营指标读取、数值归一化和同比计算。
- `04`：使用测试 ES 已覆盖的科大讯飞财务事实，供发布页影子 PASS 演示。
- `05`：使用否定性风险主张，供发布页人工 FAIL 按钮和证据覆盖边界演示。
- `06`：同一份模拟尽调内容的 Word/PDF 版本，分别验证段落和页码定位。
- `07`：两页 PPT，验证幻灯片页码和多页文本提取。
- `08`：带公式的 Excel 台账，验证工作表、单元格、单位和公式保留。

二进制材料可通过 `../competition-replay/generate-demo-documents.py` 重建；生成器不会读取公司数据。

`01`—`03`、`06`—`08` 的模拟主体不保证能从公司 ES 查到，因此“证据不足”是合理结果；`04`—`05` 是公司内部授权的真实主体测试材料，只用于影子人工观察。评测准确率必须使用 `evals/dataset.jsonl` 中带金标的固定样本，不能用这些真实任务式材料计算。
