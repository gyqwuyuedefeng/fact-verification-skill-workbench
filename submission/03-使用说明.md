# 使用说明

## 1. 打开应用

使用 Chrome 或 Edge 打开参赛人已发送给 HRBP 的 Cloudflared 链接。该地址转发本地应用，验收时参赛人的电脑、WSL 服务和 Cloudflared 需要保持运行。

左侧入口分为：

- 常规使用：事实核验对话。
- 管理控制台：演示数据、对照评测、Skill 版本、影子与发布。

当前 MVP 未实现真实账号权限，管理页面只用于比赛演示。请勿将链接转发给无关人员。

## 2. 最快查看完整结果（推荐 HRBP）

1. 打开“演示数据”。
2. 查看“当前演示数据状态”。如果七张业务表已经有数据，不要再次点击导入；直接进入第 4 步。
3. 只有七表和三个目录全部为空时，点击“导入固定脱敏内置状态”，并确认提示。
4. 打开“对照评测”，在“评测批次”查看三批固定结果，再切换“按版本汇总”和“版本对比”。
5. 选择三版本且门禁通过的批次，查看四项指标、单样本下钻和候选版门禁。
6. 打开“Skill 版本”，点击历史版本可查看只读 `SKILL.md`、References、版本卡和改动说明。
7. 打开“影子与发布”，查看影子人工通过/未通过记录，以及初始化、注册、影子、晋升和回滚的追加历史。

固定内置状态不调用模型，只用于快速浏览完整结果。页面已有数据时再次导入会提示“当前状态非空或状态合同无效”，这是防止覆盖已有演示状态的保护。

## 3. 查看普通用户核验结果

1. 打开“事实核验对话”。
2. 选择 Baseline，或在已有 Stable 时选择稳定版；普通用户看不到 Candidate 影子答案。
3. 可以直接输入文本，也可以上传 Markdown、TXT、CSV、Word、PDF、PPT、Excel。
4. 输入：

```text
请逐条核验材料中的明确企业事实。必须先确认企业主体，再核对期间、指标口径和金额单位；只能使用企业证据工具，不得使用模型记忆。证据覆盖不足时输出证据不足，不得把查询为空解释为不存在。
```

5. 提交后依次观察：

   - `01 材料解析`：解析文本、表格、段落、页码或单元格，并提取待核验主张。
   - `02 执行轨迹`：实时显示主体搜索、工商/财务/知识产权/风险/关系工具调用及完成状态。
   - `03 核验主张`：逐条显示已核实、存在冲突或证据不足，并附材料位置、证据和人工介入提示。

推荐录屏时打开一条已经完成的任务，避免等待网络和模型；旁白明确它是“已经完成的真实测试任务”。

## 4. 查看正式评价结果

1. 打开“对照评测”。
2. 在“评测批次”选择状态为“已完成”、门禁为“通过”且同时包含 Baseline、Stable、Candidate 的批次。
3. 查看“同条件锁定”：数据集、模型配置、参数、Agent 运行时、工具、证据快照和输出契约均有哈希。
4. 查看四项指标。`pp` 表示百分点；准确率从 90.00% 到 93.33% 即 `+3.33pp`。
5. 展开“单样本下钻”中的 `inspur-ip`，说明 Candidate 如何修复“空结果被当作不存在”的问题。
6. 查看“05 候选版门禁”；`05` 是内容区编号，实际列出 8 项硬检查。
7. 切换“按版本汇总”查看一个 Skill 版本关联的多次评测；切换“版本对比”查看当前版本相对上一版或当前 Stable 的指标变化。

## 5. 理解影子、晋升和回滚

- 注册：Candidate 必须关联已完成、门禁通过且包含当前 Stable 的同条件评测。
- 影子：用户仍收到 Stable 正式结果，系统在后台用 Candidate 复制同一材料运行；这不是让一部分用户偷偷收到 Candidate。
- 人工复核：管理员比较正式结果和影子结果，标记“人工通过”或“人工未通过”。影子材料没有金标准，这个按钮是发布决策，不等同于准确率。
- 晋升：只有注册成功且至少有一条影子人工通过记录，Candidate 才能成为新的 Stable。
- 回滚：恢复上一版 Stable，仅影响后续任务，历史任务和评测记录不被重写。

## 6. 危险操作

“清空并从第 1 步开始”会删除测试 schema 中七张比赛业务表的数据和三个受管目录，只能在确认没有活动任务且已经导出恢复快照后操作。HRBP 快速验收不需要点击清空、重新运行评测、晋升或回滚。

## 7. 链接异常排查

- 页面打不开：确认参赛人的 Windows 电脑、WSL 应用和 Cloudflared 均在运行。
- 页面打开但接口失败：确认本地后端 `19090` 和 MCP `19091` 健康。
- 重启 Cloudflared 后：Quick Tunnel 地址可能变化，必须重新发送新链接。
- 企业核验提示证据服务不可用：这是企业内网 ES/模型链路问题；仍可用固定脱敏状态查看完整产品链路，但不能把固定结果称为现场实时运行。
