# 企业材料事实核验 Skill 工作台——业务说明

企业尽调、融资材料、新闻稿和经营简报里经常包含成立日期、营收、专利、风险和股东关系等事实。人工逐条查库耗时，直接让通用模型回答又容易使用模型记忆、猜测主体或给出无法追溯的结论。本项目选择“企业材料事实核验”这一高频、结果可评价的真实任务，把材料中的明确主张转成可复现的证据核验流程。

普通用户通过对话页粘贴文本或上传 Markdown、TXT、CSV、DOCX、PDF、PPTX、XLSX 文件，可选择公司千问模型通用基线，或选择当前稳定版 Skill。Agent 固定材料快照和原文定位后，通过六个只读 MCP 工具解析企业主体并查询工商、财务、知识产权、风险和关系数据，最终只输出“已验证、存在冲突、证据不足”三类可追溯结论。MCP 链路原生使用 Streamable HTTP；企业查询不修改生产业务数据。

项目重点不是单次回答，而是证明 Skill 的持续优化价值。正式评测在同一 30 条金标准数据、同一模型、同一参数、同一工具合同和同一证据快照下同时运行通用基线、初始 Skill、优化 Skill。实测准确率依次为 `7/30（23.3%）`、`27/30（90.0%）`、`30/30（100.0%）`；三者任务完成率均为 100%，稳定性抽样均为 100%；人工介入率从通用基线的 80.0% 降至初始 Skill 的 26.7%，再降至优化 Skill 的 23.3%。这组结果直接证明 `无 Skill < 初始 Skill < 优化 Skill`，不是换模型得到的差异。

治理上，每个冻结版本都有不可变内容哈希、版本卡、父版本和评测关联。候选版只有通过八项离线门禁才能注册；开启影子后，普通用户仍只看到稳定版正式答案，系统后台才用同一材料与证据快照运行候选版，管理员观察差异并人工复核。通过后可晋升，异常时可回滚上一版，所有动作追加留痕。

该 MVP 已打通“材料输入—Agent 工具核验—同条件评测—版本注册—真实材料影子—晋升/回滚—报告导出”的最小闭环，可为 FireForge 全链路和启玄 App 沉淀高质量、可评测、可治理的 Skill 资产。
