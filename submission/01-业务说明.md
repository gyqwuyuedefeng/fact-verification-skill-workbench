# 企业材料事实核验 Skill Workbench

## 业务问题

企业尽调、产业研究和材料审核经常需要核对工商、财务、知识产权、风险与股权关系等事实。通用大模型能够读懂材料，却容易混淆同名主体、忽略年度与金额单位、把“查询不到”误判成“不存在”，也很难回答“这个新版本是否真的比上一版更好、出了问题能否立即恢复”。

## 解决方案

本项目基于公司同一个千问模型构建企业材料事实核验 Skill/Agent。用户可输入文本或上传 Markdown、TXT、CSV、Word、PDF、PPT、Excel；系统依次展示材料解析、执行轨迹和核验主张，并通过六个只读企业证据工具查询主体、工商、财务、知识产权、风险和关系数据。每条结论只能是已核实、存在冲突或证据不足，保留材料位置、证据记录和是否需要人工介入，不能仅凭模型记忆断言。

## 可复现结果

项目使用固定 30 条金标，在相同数据、输入、公司模型、采样参数、工具契约、证据快照和输出结构下，只改变是否加载某个冻结 Skill。当前复测中，通用模型 Baseline 准确率为 86.67%，初始 Stable 为 90.00%，优化 Candidate 为 93.33%；三者任务完成率和稳定性均为 100%，人工介入率均为 23.33%。Candidate 相比 Baseline 提升 6.66 个百分点，相比 Stable 提升 3.33 个百分点。每个汇总指标都可下钻到单条样本、金标准、原始输出和错误原因。

## 版本治理

Skill 从草稿、候选版到稳定版全程保留内容哈希、评测批次和版本卡。Candidate 必须通过样本数量、同条件锁、准确率、完成率、稳定性、人工介入率、既有失败修复和新增硬失败八项离线门禁。注册后，真实用户仍只收到 Stable 正式答案；Candidate 仅在后台复制同一输入形成影子结果，经人工复核通过后才能晋升。若线上观察异常，可一键回滚上一版，历史评测和运行记录不被覆盖。

## 业务价值

该 MVP 不试图建设通用 Agent 平台，而是交付一条可运行、可评价、可解释、可发布、可回滚的最小闭环：既形成可直接复用的企业事实核验能力，也沉淀评测集、报告、版本卡和发布记录，为后续 FireForge 全链路和启玄 App 的高质量能力供给提供可验证资产。
