# 三分钟备用视频脚本

总时长控制在 175 秒，录屏前停留在“事实核验对话”，浏览器缩放以完整展示左侧导航。

| 时间 | 页面操作 | 旁白要点 | 必须出现的证据 |
|---|---|---|---|
| 0—15 秒 | 展示首页和左侧导航 | 这是企业材料事实核验 Skill 工作台，解决通用模型主体猜测、证据不可追溯和版本效果无法证明的问题。 | 四个页面入口 |
| 15—50 秒 | Stable 输入同花顺真实材料并发送；若现场等待较长，切到已完成任务卡 | 普通用户只选择通用基线或当前稳定版，候选版不暴露。系统固定材料快照，调用只读企业证据，再输出已验证、冲突或证据不足。 | 01 输入快照、02 工具轨迹、03 主张与 recordId |
| 50—95 秒 | 打开“对照评测”，选择 `c5ce810d` | 同一 30 条金标准、同一模型参数、工具合同和证据快照，只改变 Skill。准确率是 7/30、27/30、30/30；完成率和稳定性均 100%，人工介入率持续下降。 | 三行四指标、GATE 通过 |
| 95—115 秒 | 展开 `sangfor-risk` 或 `yonyou-basic` | 单样本下钻把总分还原为金标和三变体原始输出，能直观看到优化 Skill 修复了什么。`pp` 是百分点。 | 金标、三个变体评分、原始输出入口 |
| 115—140 秒 | 打开“Skill 版本”，点击两个冻结版本 | 每个版本有内容哈希、父版本、版本卡和评测关联；优化规则解决空结果误判和地址空白归一化，冻结后不可修改。 | 两个版本号、哈希、AI 升级摘要 |
| 140—165 秒 | 打开“影子与发布” | 评测通过后先注册 Candidate，再开启影子。用户仍只看到 Stable，Candidate 在后台用同材料同证据运行。管理员看到一致 1、差异 0并人工通过，随后可晋升或回滚。 | R1—R6、同花顺影子 PASS |
| 165—175 秒 | 回到评测门禁或版本卡 | 项目已跑通数据、配置、评测、注册、影子、晋升和回滚全链路，并保留可复现报告与版本记录。 | GATE PASS 或最终 Stable |

若实时核验在 20 秒内未结束，不要空等：说明它在真实调用模型与 MCP，立即切换到页面内已完成任务或正式历史评测，保证视频总时长。
