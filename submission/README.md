## 一句话说明

这是一个面向企业材料的事实核验 Skill/Agent：在同一公司千问模型上，用 30 条固定金标把通用模型 Baseline 与两个 Skill 版本做可复现对比，再通过版本门禁、真实材料影子评审、晋升和回滚控制能力发布风险。

## 重要边界

- 当前公网入口是本地应用经 Cloudflared Quick Tunnel 暴露的临时链接，电脑、WSL 应用和 Cloudflared 必须持续运行。
- 链接没有独立登录权限，只定向发送给 HRBP，禁止公开传播；验收结束后关闭。
- “导入固定脱敏内置状态”不会调用模型，只用于快速查看完整链路，不能表述为本次现场实时评测。
- `新闻数据原始汇总.txt` 与 `真实企业材料节选.txt` 是公开材料中的待核验主张，不是金标准，也不是权威证据。
- 提交包不包含数据库、ES、模型的账号密码或内网连接信息。
