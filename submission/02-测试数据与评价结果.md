# 测试数据与评价结果

## 1. 数据分工

本提交包有三类数据，作用不能混用：

1. `dataset.jsonl`：30 条人工标注金标准，用于正式量化评价。
2. `真实企业材料节选.txt`：从公开网络材料汇总中抽取的同花顺相关主张，用于演示真实材料输入、主体消歧和证据时效性；它不是金标准。
3. 固定脱敏内置状态：用于快速查看完整版本、评测、影子、晋升与回滚界面；导入时不调用模型，不作为本次现场成绩。

## 2. 金标集

- 版本：`public-tech-2024-v3`
- 样本数：30
- 企业范围：科大讯飞、金山办公、深信服、浪潮信息、用友网络
- 类型分布：基本资料 6、财务 9、知识产权 5、风险 5、关系 5
- 金标结论：已核实 20、存在冲突 3、证据不足 7

每条样本锁定材料、预期主体、规范化主张、期望结论、证据工具与 ES `recordId`。原始索引全文不随提交包分发。

## 3. “同条件”具体锁定什么

三个变体使用同一数据集顺序、同一输入材料、同一公司千问模型、同一工具与输出契约、同一证据快照、同一超时，并固定：

- `temperature=0`
- `topP=1`
- `seed=20260812`
- `maxTokens=8192`
- `enableThinking=false`
- `parallelToolCalls=false`
- 稳定性抽样重复 3 次

唯一变化是：Baseline 不加载专用 Skill；Stable 与 Candidate 分别加载对应冻结内容哈希的 Skill。

## 4. 当前真实复测结果

评测批次：`dd376d88-21d2-4566-9e6f-16addf4e29d4`

| 变体 | 准确率 | 任务完成率 | 稳定性 | 人工介入率 |
|---|---:|---:|---:|---:|
| 通用模型 Baseline | 26/30（86.67%） | 30/30（100%） | 10/10（100%） | 7/30（23.33%） |
| 初始 Stable | 27/30（90.00%） | 30/30（100%） | 10/10（100%） | 7/30（23.33%） |
| 优化 Candidate | 28/30（93.33%） | 30/30（100%） | 10/10（100%） | 7/30（23.33%） |

Candidate 相比 Baseline 准确率提升 `+6.66pp`，相比 Stable 提升 `+3.33pp`。`pp` 是百分点：例如 90.00% 到 93.33% 是 `+3.33pp`，不是相对增长 3.33%。人工介入率越低越好，其他三项指标越高越好。

### 四项指标定义

- 准确率：主体、核验结论和核心证据均正确的金标主张数 ÷ 金标主张总数。
- 任务完成率：在 120 秒时限内完成并产生合法结构化结果的样本数 ÷ 样本总数。
- 稳定性：同条件重复运行后主体和结论一致的抽样数 ÷ 稳定性抽样总数。
- 人工介入率：主动请求确认或发布前必须修正的样本数 ÷ 样本总数。

## 5. 单样本下钻是什么

汇总指标只能说明总体效果，单样本下钻负责解释“为什么”。页面对每一条样本展示：输入材料、金标准结论、三个变体是否评分通过、运行耗时、尝试次数和原始结构化输出。

建议演示 `inspur-ip`：材料声称浪潮电子信息产业股份有限公司“存在至少一条知识产权记录”，工具结果为空。Baseline 和初始 Stable 把空结果误当反证，判为“存在冲突”；优化 Candidate 按新规则判断“当前索引未返回记录不能证明不存在”，改为“证据不足”，与金标一致。这一条直接解释了 Candidate 相比 Stable 多答对的 1 条样本。

另一条 `iflytek-risk` 说明 Stable 相比 Baseline 的改进：材料声称科大讯飞 2024 年不存在任何风险记录，工具只返回其他年份记录。Baseline 误判为冲突；Stable 识别到期间不一致和否定性主张覆盖不足，改判证据不足。

## 6. 一共有多少门禁

页面编号“05 候选版门禁”中的 `05` 是评测详情的第五块，不代表只有五个门禁。离线 Candidate 共有 8 项硬检查：

| 门禁 | 作用 |
|---|---|
| sample-count | 数据集不少于 30 条，防止用极少样本得出结论 |
| conditions-locked | 数据、模型、参数、工具、证据与输出契约必须锁定 |
| accuracy-non-regression | Candidate 正确数不得低于 Stable |
| completion-non-regression | Candidate 完成数不得低于 Stable |
| stability-non-regression | Candidate 稳定一致样本数不得低于 Stable |
| intervention-non-regression | Candidate 人工介入样本数不得高于 Stable |
| declared-failure-fixed | 至少修复一条声明的 Stable 失败样本 |
| no-new-hard-failure | 不得新增主体误配或无证据断言 |

当前复测 8 项全部通过。另有两个发布阶段门槛：注册必须关联同一 Candidate、当前 Stable 和一个已完成且门禁通过的精确评测；晋升必须至少有一条真实材料影子人工复核通过。

“回归候选准确率低于门禁”表示故意准备的回归版 Candidate 在同一金标上的正确数低于 Stable，因此被准确率不回归门禁拦截；它证明平台不只会展示成功，也能阻止更差版本发布。

## 7. 版本记录为什么有不同评测 ID

发布时版本卡保持原始绑定，不覆盖历史：

- 初始 Stable 版本卡绑定首次评测 `bc9638c9-6737-4736-ac93-77e09295a40f`。
- 优化 Candidate 版本卡和影子发布记录绑定评测 `589d49fe-f2d9-4e38-8d25-fca6051a6af9`。
- Agent 运行时增加结构化输出纠正后，又使用相同三版本完成当前复测 `dd376d88-21d2-4566-9e6f-16addf4e29d4`。

因此，当前复测报告用于说明最新运行效果，历史版本卡用于证明当时的注册、影子、晋升和回滚链路。两类证据都保留，不能为追求一个统一 ID 而改写历史。

## 8. 仍需关注的样本

当前三个变体都未答对的样本为 `inspur-finance` 和 `inspur-risk`，共同原因是“浪潮信息”简称对应多个候选主体，材料又缺少统一社会信用代码等消歧信息。系统选择人工介入而不是自动取第一个候选，说明准确率提升没有以放宽证据纪律为代价。
